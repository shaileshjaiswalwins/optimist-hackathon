# Kenney assets

This project uses selected models from:

- [Kenney Car Kit](https://kenney.nl/assets/car-kit)
- [Kenney City Kit (Roads)](https://kenney.nl/assets/city-kit-roads)

Both packs are released under Creative Commons CC0. The original license files
are included beside the selected models in their respective directories.

Only the models used by the game are included to keep the browser download
small. Kenney traffic models are used for ambient vehicles, while the bespoke
auto-rickshaw, scooter, and Thar-style player models remain project-native.
